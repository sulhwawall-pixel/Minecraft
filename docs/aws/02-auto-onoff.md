# 서버 자동으로 켜고 끄기 (PC 없이)

목표: **놀 때만 켜지고, 아무도 없으면 알아서 꺼진다. 내 컴퓨터는 꺼져 있어도 된다.**

이게 되어야 크레딧이 6개월을 갑니다.
24시간 켜두면 월 $71이라 $100 크레딧이 6주 만에 사라집니다.

```
   ┌─────────────────────────────────────────────┐
   │  끄기 — 자동                                  │
   │  30분간 접속자 없음 → 인스턴스 스스로 정지       │
   │  (설치만 하면 끝. 신경 쓸 것 없음)              │
   └─────────────────────────────────────────────┘
   ┌─────────────────────────────────────────────┐
   │  켜기 — 셋 중 골라서                           │
   │  A. 폰으로 링크 클릭   ← 추천                   │
   │  B. AWS 모바일 앱                             │
   │  C. 정해진 시간에 자동                          │
   └─────────────────────────────────────────────┘
```

---

## 끄기 — 이미 자동입니다

[설치 문서 5단계](01-setup.md#5-비용-절감-장치-설치--이게-핵심입니다)에서
`install-cost-savers.sh`를 돌렸다면 끝났습니다.

5분마다 서버에 접속자 수를 물어보고, **30분간 아무도 없으면** 월드를 저장한 뒤
인스턴스를 정지시킵니다. 서버가 크래시로 죽어 있어도 마찬가지로 정지시켜서
요금이 새지 않게 합니다.

```bash
systemctl list-timers minecraft-idle-shutdown.timer   # 다음 검사 시각
journalctl -t mc-idle -n 30                           # 판단 기록
sudo nano /etc/minecraft-idle.conf                    # 시간 조정
```

`IDLE_CHECKS`는 5분 단위입니다. `6`이면 30분, `12`면 1시간입니다.

> ⚠️ **인스턴스의 종료 동작이 `중지(Stop)`인지 반드시 확인하세요.**
> `종료(Terminate)`면 자동 종료가 걸릴 때 인스턴스가 삭제됩니다.
> EC2 콘솔 → 인스턴스 선택 → 작업 → 인스턴스 설정 → 종료 동작 변경

## 켜기 A — 폰으로 링크 클릭 (추천)

Lambda 함수 URL을 하나 만들어두면, **폰 브라우저에서 링크만 누르면 서버가 켜집니다.**
AWS 로그인도, PC도 필요 없습니다. 링크를 친구들에게 주면 누구나 켤 수 있습니다.

Lambda는 상시 무료 사용량(월 100만 요청)에 들어가서 **요금이 사실상 0원**입니다.

IAM 역할·Lambda 함수·함수 URL을 손으로 만들면 클릭이 꽤 많습니다.
그래서 **한 번에 만들어주는 템플릿**을 준비해뒀습니다.

### ① 준비물 두 가지

**EC2 인스턴스 ID** — EC2 콘솔의 인스턴스 목록에서 `i-0abc123...` 형태로 보입니다.

**암호(Secret)** — 링크에 붙일 열쇠입니다. 아무 데서나 만드세요:

```bash
openssl rand -hex 16
```

윈도우라면 PowerShell에서:
```powershell
-join ((48..57)+(97..102) | Get-Random -Count 32 | % {[char]$_})
```

이 값을 메모해두세요. 나중에 링크에 붙여야 합니다.

### ② 스택 생성 — 클릭 몇 번이면 끝

1. 저장소의 [`aws/start-button.yaml`](../../aws/start-button.yaml) 파일을 PC에 저장
   (깃허브에서 파일 열고 **Download raw file**)
2. **콘솔 → CloudFormation → 스택 생성 → 새 리소스 사용(표준)**
   - ⚠️ 리전이 **EC2 인스턴스와 같은 리전**인지 확인하세요 (우측 상단)
3. **템플릿 파일 업로드** → 방금 받은 `start-button.yaml` 선택 → 다음
4. 스택 이름: `minecraft-start-button`
5. 파라미터 입력:

| 항목 | 값 |
|---|---|
| `InstanceId` | `i-0abc123...` |
| `Secret` | ①에서 만든 문자열 |
| `Hostname` | `내도메인.duckdns.org` (없으면 비워두세요) |

6. 다음 → 다음 → 맨 아래 **"AWS CloudFormation이 IAM 리소스를 생성할 수 있음을
   승인합니다"** 체크 → **제출**

1~2분 뒤 상태가 **CREATE_COMPLETE** 가 되면 완료입니다.

### ③ 링크 받기

스택 화면의 **출력(Outputs)** 탭을 엽니다.

- `BaseUrl` 값을 복사하고, 뒤에 **`?key=아까만든Secret`** 을 붙이세요

```
https://xxxxx.lambda-url.ap-northeast-2.on.aws/?key=여기에암호
```

**이 링크를 폰 홈 화면에 추가**해두면 아이콘 하나로 서버가 켜집니다.
친구들에게도 이 링크를 주세요.

> `Secret`은 보안상 CloudFormation 화면에 다시 표시되지 않습니다.
> 잃어버리면 스택을 업데이트해서 새로 넣으면 됩니다.

### ④ 테스트

인스턴스를 정지시킨 뒤 링크를 눌러보세요.
**"서버를 켰습니다"** 화면이 뜨고 2~3분 뒤 접속되면 성공입니다.

이미 켜져 있으면 "이미 켜져 있습니다", 링크가 틀리면 "접근할 수 없습니다"가 뜹니다.

### 안전장치

- IAM 권한이 **그 인스턴스 하나를 켜는 것**과 **상태 조회**로만 제한돼 있습니다.
  링크가 유출돼도 다른 리소스는 건드리지 못합니다
- 인증 유형이 NONE이라 URL을 아는 사람은 누구나 접근할 수 있어서 `Secret`으로
  막아둔 것입니다. 링크를 공개된 곳에 올리지 마세요
- 최악의 경우라도 **서버가 켜지는 것 이상은 할 수 없습니다.**
  그리고 켜져도 30분 뒤 유휴 자동 종료가 다시 꺼줍니다

### 지우고 싶을 때

CloudFormation에서 **스택 삭제**를 누르면 역할·함수·URL이 한꺼번에 정리됩니다.

### 손으로 만들고 싶다면

콘솔에서 직접 만들고 싶으면 [`aws/lambda/start_server.py`](../../aws/lambda/start_server.py)
(함수 코드)와 [`aws/lambda/iam-policy.json`](../../aws/lambda/iam-policy.json)
(IAM 정책)을 쓰면 됩니다. 환경 변수는 `INSTANCE_ID`, `SECRET`, `HOSTNAME`이고
런타임은 Python 3.12, 제한 시간은 30초로 잡으세요.

## 켜기 B — AWS 모바일 앱 (설정 0)

Lambda 만들기가 번거로우면 이게 제일 빠릅니다.

1. **AWS Console** 앱 설치 (iOS / Android)
2. 로그인 → EC2 → 인스턴스 선택 → **시작**

설정할 게 전혀 없고 무료입니다. 단점은 **본인만 켤 수 있다**는 것 —
친구들이 먼저 놀고 싶어도 직접 켜줘야 합니다.

## 켜기 C — 정해진 시간에 자동 (EventBridge)

"매일 저녁 7시엔 무조건 켜져 있으면 좋겠다" 하는 경우입니다.
Lambda와 **같이 써도 됩니다.**

**콘솔 → Amazon EventBridge → 스케줄러 → 일정 생성**

1. 일정 패턴: **되풀이 일정**, cron 기반
2. cron 식: `0 10 * * ? *` → **매일 한국시간 저녁 7시**
   - EventBridge는 UTC 기준입니다. 한국시간 = UTC + 9
   - 저녁 7시(19시) → UTC 10시
   - 또는 시간대 설정에서 `Asia/Seoul`을 직접 고를 수도 있습니다
3. 대상: **AWS Lambda → Invoke** → 아까 만든 `start-minecraft` 선택
4. 생성

끄는 일정은 만들 필요가 없습니다. 유휴 자동 종료가 알아서 합니다.

> 아무도 안 놀 날에도 켜지면 30분치 요금(약 $0.04)이 나갑니다.
> 큰돈은 아니지만, 주말에만 켜지게 하려면 cron을 `0 10 ? * SAT,SUN *` 로 바꾸세요.

## 완전 자동은 안 되나? (접속 시도만으로 켜지기)

마크 클라이언트에서 서버를 클릭하면 알아서 켜지는 것도 기술적으로 가능합니다.
Route 53 DNS 쿼리 로그를 CloudWatch로 보내고 Lambda를 트리거하는 방식입니다.

다만 **도메인 구입 + 호스팅 영역 $0.50/월**이 들고 설정이 훨씬 복잡합니다.
처음이시라면 **A(링크 클릭)** 로 시작하시길 권합니다. 실사용에서 불편이 거의 없습니다.

## 정리

| | 설정 난이도 | 비용 | 친구도 켤 수 있나 |
|---|---|---|---|
| **A. 링크 클릭** | 5분 (템플릿 업로드) | ~0원 | ✅ |
| B. 모바일 앱 | 0분 | 0원 | ❌ |
| C. 정해진 시간 | 5분 | ~0원 | (자동) |

**추천 조합: A + 유휴 자동 종료.**
친구가 놀고 싶으면 링크 누르고, 다 놀면 30분 뒤 알아서 꺼집니다.
아무도 신경 쓸 필요가 없고 크레딧도 아낍니다.
