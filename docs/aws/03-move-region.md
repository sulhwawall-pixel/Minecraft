# 리전을 잘못 골랐을 때 — 옮기기

**처음부터 다시 설치할 필요 없습니다.**
이미지를 떠서 원하는 리전으로 복사하면 **모드팩·Forge·설정·월드·자동종료까지
전부 그대로** 넘어갑니다. SSH에서 명령을 다시 칠 일도 없습니다.

전체 40분쯤 걸리는데, 대부분은 복사가 끝나기를 기다리는 시간입니다.

> 기존 `.pem` 키를 그대로 씁니다. 인스턴스로 이미지를 만들면 공개키가 함께
> 복사되고, Ubuntu의 cloud-init은 기존 키를 덮어쓰지 않고 추가하기 때문입니다.

---

## 1. 잘못된 리전에서 — 이미지 뜨기

콘솔 우측 상단 리전이 **원래(잘못 만든) 리전**인 상태에서:

1. **EC2 → 인스턴스** → 내 서버 선택
2. **인스턴스 상태 → 인스턴스 중지** — 완전히 멈출 때까지 기다립니다
   (켜둔 채로도 되지만, 꺼두면 파일이 저장 중인 상태로 찍히지 않아 안전합니다)
3. 인스턴스 선택 → **작업 → 이미지 및 템플릿 → 이미지 생성**
4. 이미지 이름 `sunlit-backup` → **이미지 생성**

왼쪽 메뉴 **AMI** 로 가서 상태가 **`사용 가능(available)`** 이 될 때까지
기다립니다. **5~10분.**

## 2. 목표 리전으로 복사

1. **AMI** 목록에서 `sunlit-backup` 선택
2. **작업 → AMI 복사**
3. **대상 리전: 아시아 태평양(서울) ap-northeast-2**
4. **AMI 복사**

**10~20분** 걸립니다. 50GB를 대륙 건너로 옮기는 중입니다.

## 3. 서울에서 인스턴스 만들기

**우측 상단 리전을 서울로 바꿉니다.**

왼쪽 메뉴 **AMI** 에서 복사된 이미지가 `available` 인지 확인한 뒤:

1. 이미지 선택 → **AMI에서 인스턴스 시작**
2. 설정:

| 항목 | 값 |
|---|---|
| 이름 | `minecraft-sunlit` |
| 인스턴스 유형 | **`m7i-flex.large`** |
| 키 페어 | **새 키 페어 생성** → `minecraft-seoul`<br>(기존 `.pem` 도 계속 작동합니다) |
| 보안 그룹 | **새로 생성** → SSH 22(내 IP) + **사용자 지정 TCP 25565 (`0.0.0.0/0`)** |
| 스토리지 | 이미지 그대로 (건드릴 필요 없음) |
| 고급 → **종료 동작** | **중지(Stop)** ← 확인 |

> 보안 그룹도 리전에 묶여 있어서 새로 만들어야 합니다.
> **25565 규칙을 빠뜨리면 서버는 켜지는데 접속이 안 됩니다.**

3. **인스턴스 시작**

## 4. 확인

새 퍼블릭 IP로 접속:

```bash
ssh -i minecraft.pem ubuntu@새IP
```

```bash
sudo mcctl status
```

- 마크 서버는 부팅 때 **자동으로 켜집니다** (systemd에 등록되어 있음)
- DuckDNS를 설정해뒀다면 **새 IP로 알아서 갱신**됩니다
- 유휴 자동 종료도 그대로 따라옵니다

## 5. ⚠️ 원래 리전 정리 — 안 하면 크레딧이 계속 나갑니다

인스턴스를 **꺼두기만 해도 EBS 요금은 계속** 나갑니다. 반드시 지우세요.

콘솔 우측 상단 리전을 **원래(잘못 만든) 리전**으로 바꾼 뒤:

| 순서 | 위치 | 할 일 |
|---|---|---|
| 1 | CloudFormation | 스택을 만들었다면 **스택 삭제** |
| 2 | EC2 → 인스턴스 | **인스턴스 종료(Terminate)** ← 중지 아님 |
| 3 | EC2 → AMI | `sunlit-backup` → **작업 → AMI 등록 취소** |
| 4 | EC2 → 스냅샷 | 남아 있는 스냅샷 **삭제** |
| 5 | EC2 → 볼륨 | 남은 볼륨이 없는지 확인 |

3~5번을 건너뛰면 스냅샷 요금이 조금씩 계속 나갑니다.

## 6. 시작 버튼 다시 만들기

Lambda 시작 버튼은 **인스턴스 ID를 지정해서 만들어지므로** 서울에서 새로
만들어야 합니다. 파일 업로드 한 번이라 5분입니다.

새 인스턴스 ID를 복사해서 → [자동으로 켜고 끄기](02-auto-onoff.md#켜기-a--폰으로-링크-클릭-추천)
