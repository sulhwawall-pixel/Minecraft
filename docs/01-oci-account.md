# 1단계 — OCI 계정 만들기

소요 시간 약 20분. 신용카드가 필요하지만 **실제 결제는 되지 않습니다** (본인 확인용으로
1달러 정도가 잠시 잡혔다가 며칠 내 취소됩니다).

---

## 가입

1. https://www.oracle.com/kr/cloud/free/ 접속 → **무료로 시작하기**
2. 국가: **대한민국**, 이메일 입력 → 인증 메일 확인
3. 계정 유형: **개인(Individual)**
4. 이름/주소/휴대폰 인증
5. 결제 수단 등록

### 결제 수단 주의사항

| 카드 | 결과 |
|---|---|
| 국내 **신용카드** (Visa / Mastercard) | 대부분 통과 |
| 체크카드 / 직불카드 | 자주 거절됨 |
| 트래블월렛 등 선불 카드 | 거의 거절됨 |
| 카카오뱅크·토스 체크카드 | 사례가 갈림 |

**해외 결제가 열려 있는 신용카드**를 쓰는 게 가장 확실합니다. 거절되면 카드사 앱에서
해외 온라인 결제 차단이 걸려 있는지 먼저 확인하세요.

---

## "계정을 생성하는 중 오류가 발생했습니다" 가 뜬다면

```
등록을 완료할 수 없습니다. 등록을 방해하는 일반적인 오류는 다음과 같습니다.
 a) 정보 입력을 완료하지 않았거나 잘못 입력했습니다.
 b) 위치 또는 ID를 의도적으로 또는 실수로 마스킹했습니다.
 c) 여러 계정을 생성하려고 시도했습니다.
```

**이 메시지는 실제 원인을 알려주지 않습니다.** 오라클이 어뷰징 방지를 위해 서로 다른
실패 원인을 전부 같은 문구로 묶어놨기 때문입니다. 그래서 하나씩 지워가며 찾아야 합니다.

한국 사용자에게 흔한 순서대로 정리했습니다.

### ① 영문 주소 입력 형식 — 가장 흔합니다

주소를 **Address 1 / 2 / 3 에 나눠서 입력하면 실패**하는 사례가 많습니다.

- **Address 1 한 칸에 전체 영문 주소를 몰아서** 넣고, Address 2·3은 **비워두세요**
- 영문 주소는 [네이버 영문주소 변환](https://map.naver.com) 또는
  [주소찾아 영문변환](https://www.jusoen.com) 결과를 **그대로** 복사해 쓰세요
- 임의로 줄이거나 한글을 섞지 마세요
- **카드 청구지 주소와 일치**해야 합니다

### ② 카드 문제

| 확인 항목 | 내용 |
|---|---|
| 카드 종류 | **선불카드는 무조건 거부**됩니다. 트래블월렛·트래블로그 등 전부 안 됩니다 |
| 해외결제 | 카드사 앱에서 **해외 온라인 결제가 차단돼 있는지** 확인 |
| DCC(해외원화결제) | 켜져 있으면 실패했다는 후기가 많습니다. **카드사 앱에서 "해외원화결제 차단 서비스"를 신청**해보세요 |
| 카드 한도 | 본인 확인용으로 1달러 정도가 승인되어야 합니다 |

신용카드가 가장 확실하지만, 체크카드로 성공한 사례도 있습니다.
한 카드로 계속 실패하면 **다른 카드사 카드**로 바꿔보세요.

### ③ 위치가 가려진 것으로 판정 (b번 항목)

오라클은 IP를 꽤 민감하게 봅니다. 아래를 **전부** 끄고 다시 시도하세요.

- VPN, 프록시, Cloudflare WARP
- 광고 차단 DNS (AdGuard DNS, NextDNS 등)
- 브라우저 확장 프로그램 (uBlock, Privacy Badger 등)
- 회사·학교 네트워크

**크롬 시크릿 모드**로 하는 게 가장 깔끔합니다.
그래도 안 되면 **휴대폰 LTE 테더링**으로 IP를 바꿔서 시도해보세요. 이것만으로
해결되는 경우가 꽤 있습니다.

### ④ 중복 계정으로 판정 (c번 항목)

무료 체험은 **1인 1회**입니다. 다음이 하나라도 겹치면 걸립니다.

- 예전에 가입한 적 있는 **이메일**
- 이미 쓴 적 있는 **휴대폰 번호**
- 이미 쓴 적 있는 **카드**
- 같은 집에서 가족이 이미 가입한 경우 (같은 IP + 같은 주소)

**계정을 삭제했어도 이력은 남습니다.** 짚이는 게 있다면 새 이메일 + 다른 카드로
시도하는 수밖에 없습니다.

### 실패 후에는 24시간 기다리세요

연속으로 실패하면 일시적으로 차단됩니다. 같은 조건으로 계속 재시도하면
오히려 더 막힙니다. **하루 뒤에** 위 항목들을 고쳐서 다시 시도하세요.

### 그래도 안 되면 — 오라클에 직접 문의

이게 의외로 잘 먹힙니다. 상담원이 계정 쪽 플래그를 풀어주고
"이 메일로 다시 가입하세요"라고 안내해주는 사례가 많습니다.

- [Oracle Cloud 무료 티어 페이지](https://www.oracle.com/kr/cloud/free/) 우측 하단 **채팅**
- 또는 https://www.oracle.com/kr/corporate/contact/ 에서 문의

문의할 때 이렇게 적으면 빠릅니다:
> Oracle Cloud Free Tier 가입 시 "We are unable to complete your sign up"
> 오류가 반복됩니다. VPN을 쓰지 않았고, 신용카드와 영문 주소를 정확히 입력했습니다.
> 계정 검토를 요청드립니다. (가입 시도한 이메일: ______)

---

## 홈 리전 선택 — 되돌릴 수 없습니다

가입 중에 **홈 리전(Home Region)** 을 고르는 화면이 나옵니다.
**한 번 정하면 바꿀 수 없고, 무료 티어 리소스는 홈 리전에서만 만들 수 있습니다.**

### 결론부터: 한국 리전은 선택지가 아닙니다

목록에 한국이 안 보인다고 해도 정상입니다. 두 리전 모두 무료 ARM 서버에는 쓸 수 없습니다.

| 리전 | 코드 | 한국에서 핑(대략) | 무료 ARM 사용 가능? |
|---|---|---|---|
| 대한민국 중부(서울) | `ap-seoul-1` | ~5ms | 신규 무료 가입 시 **홈 리전 목록에 거의 안 뜸** |
| 대한민국 북부(춘천) | `ap-chuncheon-1` | ~10ms | **❌ 불가.** 오라클이 공식적으로 제외한 리전 |
| **일본 동부(도쿄)** | `ap-tokyo-1` | 30~40ms | ✅ **1순위 추천** |
| **일본 중부(오사카)** | `ap-osaka-1` | 35~45ms | ✅ 2순위. 도쿄보다 자리 여유가 있는 편 |
| 싱가포르 | `ap-singapore-1` | 70~90ms | ✅ 가능하지만 핑이 부담됨 |

- **서울**은 무료 티어 수요가 몰려서 신규 가입 시 홈 리전 선택 목록에서 빠져 있는
  상태입니다.
- **춘천**은 목록에 뜨더라도 **고르면 안 됩니다.** 오라클 공식 문서에
  "Ampere A1 인스턴스는 **South Korea North(Chuncheon)를 제외한** 모든 가용성
  도메인에서 생성할 수 있다"고 명시돼 있습니다. 춘천을 홈 리전으로 잡으면
  무료 ARM 서버를 아예 못 만들고, 홈 리전은 되돌릴 수 없습니다.

### 추천: 도쿄(`ap-tokyo-1`)

**핑 30~40ms는 마인크래프트에서 체감되지 않습니다.** 블록 캐고 농사짓는 데는
아무 문제 없고, PvP를 빡세게 하는 게 아니라면 서울과 실질적인 차이가 없습니다.

도쿄에서 계속 "Out of host capacity"가 뜬다면 **오사카**가 대안입니다.
자리 문제 대처법은 [2단계 문서](02-create-instance.md#out-of-host-capacity-가-뜬다면)에
정리해뒀습니다.

> 목록에 일본도 없다면, 뜨는 것 중 아시아·태평양 지역을 고르세요.
> 미국·유럽 리전은 핑이 130ms를 넘어가서 플레이가 확실히 답답해집니다.

## 가입 후 — 반드시 확인할 것

가입하면 **30일 / $300 무료 크레딧 체험 기간**이 시작됩니다.
이 기간에는 유료 리소스도 만들어지기 때문에, 모르고 비싼 사양을 만들면
30일 뒤에 그 서버가 **정지되고 삭제**됩니다 (청구되진 않지만 월드가 날아갑니다).

따라서 다음 단계에서 인스턴스를 만들 때:

- 반드시 **"항상 무료 적격 (Always Free eligible)"** 초록 라벨을 확인
- Shape는 **VM.Standard.A1.Flex** (Ampere ARM)
- 2 OCPU / 12 GB 를 넘기지 말 것

체험 기간이 끝나면 계정은 자동으로 **Always Free** 계정으로 전환되고,
무료 범위 안의 리소스는 계속 그대로 돌아갑니다.

### 예산 알림 걸어두기 (선택이지만 권장)

콘솔 좌측 메뉴 → **결제 및 비용 관리 → 예산(Budgets)** → 예산 생성
→ 금액 `1 USD`, 알림 임계값 `100%`.

무료 범위를 벗어나 뭔가 과금되기 시작하면 메일이 옵니다. 마음이 편해집니다.
