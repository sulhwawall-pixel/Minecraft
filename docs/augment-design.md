# 마인크래프트 증강체(Augment) 시스템 설계안

롤토체스(TFT)의 증강체를 마인크래프트 서바이벌에 이식하기 위한 기획 문서.

---

## 1. 왜 그대로 옮기면 안 되는가

TFT 증강체가 재미있는 이유는 세 가지 조건 때문이다.

1. **강제된 선택 시점** — 라운드가 정해져 있어 "지금 결정해야 한다"는 압박이 있다.
2. **되돌릴 수 없음** — 한 번 고르면 그 판은 그 빌드로 간다.
3. **판이 짧음** — 30분이면 끝나므로 실패해도 다시 하면 된다.

마인크래프트는 셋 다 없다. 라운드가 없고, 월드는 수백 시간 이어지고, 뭐든 나중에 다시 파면 된다.
그래서 **"언제 주는가"를 새로 설계하는 것이 증강체 목록보다 훨씬 중요하다.**

핵심 결론: **진행도(progression) 기반 트리거**를 쓴다. 시간 기반은 안 된다 —
집에 숨어서 시간만 흘려도 증강체가 쌓이면 도전 없이 보상만 먹는 구조가 된다.

---

## 2. 획득 구조

### 2.1 트리거 (진행도 게이트)

| 단계 | 트리거 | 티어 확률 (실버/골드/프리즘) |
|---|---|---|
| 1 | 첫 밤 생존 (Day 1 → Day 2 전환) | 100 / 0 / 0 |
| 2 | 다이아몬드 최초 획득 | 70 / 30 / 0 |
| 3 | 네더 최초 진입 | 50 / 45 / 5 |
| 4 | 블레이즈 최초 처치 | 30 / 55 / 15 |
| 5 | 엔더의 눈 최초 제작 | 15 / 60 / 25 |
| 6 | 엔드 진입 | 0 / 60 / 40 |
| 7+ | 보스 처치마다 (엔더 드래곤 / 위더 / 워든) | 0 / 40 / 60 |

- 발전 과제(advancement) 트리거를 그대로 재사용할 수 있어 구현이 싸다.
- 최종적으로 한 월드당 **7~9개**를 갖게 된다. 너무 많으면 개성이 사라진다.

### 2.2 선택 방식

- **3개 중 1개** 선택. TFT와 동일.
- **리롤**: 에메랄드 3개 소모, 판당 총 2회 제한. (엔더 진주로 하면 더 마크스럽다는 의견도 있음)
- 선택창이 뜨면 **게임이 멈추지 않는다.** 대신 선택 전까지 UI가 계속 떠 있고,
  선택하지 않아도 플레이는 가능하다. 몹에게 쫓기면서 고르는 상황 자체가 긴장감이 된다.

### 2.3 티어 정의

- **실버**: 수치 보정. "채굴 속도 +15%" 같은 것. 항상 무난하게 좋다.
- **골드**: 플레이 방식을 살짝 바꿈. 조건부 트리거, 새로운 상호작용.
- **프리즘**: 그 월드의 정체성이 됨. 하나만 있어도 "이번 판은 ○○ 판"이 되는 것.

## 3. 태그(시너지) 시스템

증강체 하나하나가 강한 것보다, **모아서 완성되는 그림**이 있어야 롤토체스답다.
각 증강체에 태그를 1~2개 붙이고, 같은 태그 3개를 모으면 **각성(Awakening)**이 열린다.

| 태그 | 컨셉 | 3중첩 각성 효과 |
|---|---|---|
| ⛏️ **광부** | 지하, 자원, 채굴 | *심층의 눈* — 반경 16칸 광석이 상시 실루엣으로 보임 |
| ⚔️ **전사** | 근접 전투 | *전장의 지배자* — 5초 내 처치 수마다 공격력 누적 +10% (최대 5중첩) |
| 🏹 **사냥꾼** | 원거리, 기동 | *바람의 인도* — 화살이 적을 자동 추적, 헤드샷 판정 추가 |
| 🌾 **정착민** | 농사, 주민, 건축 | *풍요의 땅* — 반경 32칸 작물 성장 3배, 주민 거래 무한 |
| 🔥 **방랑자** | 차원 이동, 탐험 | *차원의 문턱* — 방문했던 좌표로 3분 쿨다운 텔레포트 |
| 💀 **금기** | 양날의 검, 저주 | *대가의 정산* — 모든 금기 증강체의 페널티 절반, 이득 그대로 |

선택지 3개를 뽑을 때 **이미 보유한 태그에 가중치**를 준다.
그래야 "광부 빌드가 굴러가는" 경험이 생기고, 억지로 안 맞는 걸 고르는 일이 줄어든다.

## 4. 증강체 목록

### 4.1 실버 (수치형 / 안정적)

| 이름 | 태그 | 효과 |
|---|---|---|
| **곡괭이 감각** | 광부 | 광석 채굴 시 10% 확률로 드랍 2배 (행운과 중첩) |
| **깊은 폐** | 광부 | 수중 호흡 +8초, 어둠 속 시야 약간 밝아짐 |
| **굳은살** | 전사 | 근접 피해 15% 증가, 넉백 저항 20% |
| **흡혈귀의 이빨** | 전사 | 근접 피해의 12%만큼 체력 회복 |
| **활시위 강화** | 사냥꾼 | 활/석궁 충전 속도 30% 증가 |
| **가벼운 발** | 사냥꾼, 방랑자 | 낙하 피해 50% 감소, 이동 속도 +8% |
| **미식가** | 정착민 | 모든 음식의 포만감 1.5배, 황금 사과 지속시간 2배 |
| **초록 손** | 정착민 | 뼛가루 사용 시 50% 확률로 소모 안 됨 |
| **여행자의 지도** | 방랑자 | 지도 제작 무료, 미탐험 청크 진입 시 경험치 소량 획득 |
| **재활용** | 광부, 정착민 | 도구/방어구를 제작대에 넣으면 재료 50% 반환 |

### 4.2 골드 (조건부 / 플레이 변화)

| 이름 | 태그 | 효과 |
|---|---|---|
| **정맥 감지** | 광부 | 곡괭이를 들고 웅크리면 반경 12칸 광석 실루엣 5초 표시 (쿨 20초) |
| **지열 발전** | 광부 | Y ≤ 0에서 채굴 속도 +40%, 용암 피해 70% 감소 |
| **광부의 이자** | 광부 | 지정한 "금고" 상자에 든 에메랄드 10개당, 밤이 지날 때 1개 추가 (최대 5개/일) |
| **처형자** | 전사 | 체력 30% 이하의 적에게 주는 피해 2배 |
| **최후의 저항** | 전사 | 체력 4칸 이하일 때 피해량 +50%, 받는 피해 -25% |
| **연쇄 처형** | 전사 | 몹 처치 시 주변 5칸 적에게 처치 대상 최대 체력의 25% 피해 |
| **관통 사격** | 사냥꾼 | 화살이 적 3명까지 관통, 관통마다 피해 -20% |
| **엔더 대시** | 사냥꾼, 방랑자 | 엔더 진주 쿨다운 제거 + 텔레포트 피해 없음 + 진주가 30% 확률로 회수됨 |
| **즉흥 건축** | 정착민 | 블록 설치 시 12% 확률로 소모되지 않음. 비계/발판 무한 |
| **대장장이의 눈** | 정착민, 광부 | 모루 작업 비용 0, 인챈트 테이블 결과 레벨 +1 |
| **양치기** | 정착민 | 길들인 동물이 나를 따라오며 몹을 공격. 늑대 최대 체력 3배 |
| **포탈 애호가** | 방랑자 | 네더 포탈 즉시 이동, 좌표 배율 1:16 → 1:24 |
| **밤의 아이** | 방랑자, 금기 | 밤: 이동속도 +25%, 공격력 +25% / 낮: 둘 다 -15% |
| **채식주의자** | 정착민, 금기 | 고기류를 먹을 수 없음. 대신 작물 음식 포만감 3배 + 재생 효과 |
| **유리 대포** | 전사, 금기 | 모든 피해량 2배, 최대 체력 절반(10) |

### 4.3 프리즘 (판을 정의함)

| 이름 | 태그 | 효과 |
|---|---|---|
| **미다스의 손** | 광부 | 채굴한 모든 돌 계열 블록의 3%가 금괴로 변환. 금 장비의 내구도 10배 |
| **심층의 부름** | 광부, 금기 | Y ≤ -40에서 모든 능력치 +80%, 지상(Y ≥ 64)에서는 -30% |
| **도플갱어** | 전사 | 나를 따라다니는 그림자 분신 소환. 내 장비의 60% 성능으로 함께 싸움. 죽으면 5분 후 부활 |
| **폭풍의 화신** | 전사, 사냥꾼 | 공격 시 10% 확률로 낙뢰(화재 없음). 비가 올 때 확률 3배 |
| **무한의 화살통** | 사냥꾼 | 화살 소모 없음. 대신 활 피해량 25% 감소 |
| **만물상** | 정착민 | 모든 주민이 최고 등급으로 시작, 거래 가격 절반, 거래 제한 없음 |
| **시간의 주인** | 정착민, 방랑자 | 낮의 길이 2배, 밤의 길이 절반. 침대 없이도 밤에 시간 가속 가능 |
| **차원 도둑** | 방랑자 | 차원 이동 시 랜덤한 실버 증강체 1개를 60초간 임시 획득 |
| **영혼의 계약** | 금기 | 사망 시 인벤토리 전부 유지. 대신 사망할 때마다 최대 체력 영구 -2 (최소 6) |
| **하나뿐인 목숨** | 금기 | 최대 체력 6. 모든 능력치 +100%. 사망 시 월드가 하드코어로 전환 |
| **수집가의 광기** | 금기, 정착민 | 인벤토리 슬롯 9칸으로 축소. 대신 소지한 아이템 종류 수 × 3% 만큼 모든 능력치 증가 |

## 5. 빌드 예시 (실제로 이렇게 굴러간다)

**동굴 잠수함 빌드** — 광부 3중첩
> 곡괭이 감각 → 지열 발전 → 심층의 부름 → 각성 *심층의 눈*
> Y = -50에 베이스를 짓고 거의 지상에 올라오지 않는다. 지하에서는 무적에 가깝지만
> 지상 몹 사냥은 포기해야 한다. 네더 진출이 오히려 편해진다.

**한 방 빌드** — 전사 + 금기
> 유리 대포 → 처형자 → 최후의 저항
> 체력 5칸으로 크리퍼 한 방에 죽지만, 워든도 몇 대에 녹는다. 손이 떨린다.

**마을 제국 빌드** — 정착민 3중첩
> 즉흥 건축 → 만물상 → 초록 손 → 각성 *풍요의 땅*
> 전투를 거의 안 하고 주민 거래와 농사로 모든 것을 해결한다.
> 대신 몹 앞에서는 여전히 약하므로 방어 건축이 필수가 된다.

**핵심**: 세 빌드 모두 *"할 수 있는 것"만 늘어난 게 아니라 "못 하는 것"이 생겼다.**
증강체가 재미있으려면 포기하는 게 있어야 한다.

## 6. 멀티플레이 — 여기가 진짜 노림수

각 플레이어가 **다른 증강체 풀**에서 뽑게 하면, 서버에 자연스러운 역할 분담이 생긴다.

- 광부 빌드가 자원을 캐 오고, 전사 빌드가 호위하고, 정착민 빌드가 거점을 짓는다.
- 아무도 "그냥 다 잘하는 캐릭터"가 될 수 없다.
- 파티 구성 자체가 **롤토체스의 덱 구성**이 된다.

추가 규칙 제안:
- 같은 서버에서 **이미 다른 사람이 가진 프리즘 증강체는 등장하지 않는다.** (유일성)
- **증강체 거래**: 두 플레이어가 합의하면 서로의 증강체 1개를 교환할 수 있다. 월드당 1회.

## 7. 구현 노트

### 데이터팩만으로 가능한 것
- 트리거: `advancement` + `function` 조합
- 상태 저장: `scoreboard` 또는 플레이어 NBT 태그
- 수치 보정: `/attribute` 명령 (이동속도, 공격력, 최대 체력, 채굴 속도, 넉백 저항)
- 조건부 효과: `execute if` 를 매 틱 돌리는 함수 — 단, 증강체 개수 × 플레이어 수만큼
  조건 검사가 늘어나므로 **보유한 증강체에 해당하는 함수만 태그로 걸어 호출**해야 한다
- 선택 UI: 셜커 상자 인벤토리를 GUI처럼 쓰거나, `tellraw` 클릭 이벤트

### 모드가 필요한 것
- 진짜 선택 화면 (아이콘 + 설명 + 호버 툴팁)
- 광석 실루엣 렌더링 (X-ray 스타일 오버레이)
- 도플갱어 같은 커스텀 엔티티 AI
- 인벤토리 슬롯 수 변경

### 권장 진행
1. **1차 프로토타입**: 데이터팩으로 실버 10종 + 트리거 3단계만. `tellraw` UI로 충분.
2. 밸런스가 잡히면 골드/프리즘 확장.
3. UI와 렌더링이 필요해지는 시점에 Fabric 모드로 이식.

### 밸런스 원칙
- **실버는 절대 판을 못 바꾼다.** 실버끼리 비교했을 때 "이건 무조건 이거지"가 나오면 실패.
- **프리즘은 반드시 페널티나 조건이 있다.** 순수 상향은 프리즘이 아니라 그냥 치트다.
- **"안 고르면 손해"가 아니라 "뭘 골라도 다른 판이 된다"**가 목표.

## 8. 열린 질문

- 리롤 비용을 에메랄드로 할지, 경험치 레벨로 할지 — 경험치는 인챈트와 경쟁하므로 더 아플 수 있다.
- 죽으면 증강체를 잃게 할 것인가? (하드코어 변형에서만 적용하는 게 안전해 보인다)
- 크리에이티브/치트 사용 시 증강체 비활성화 여부
- 기존 월드에 데이터팩을 적용했을 때, 이미 지나간 트리거를 소급 지급할지
