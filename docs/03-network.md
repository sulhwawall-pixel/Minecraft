# 3단계 — 네트워크 열기 (25565 포트)

**서버 구축에서 가장 많이 막히는 지점입니다.** OCI에는 방화벽이 **두 겹**이라,
하나만 열면 접속이 안 됩니다.

```
   친구 마크 클라이언트
          │
          ▼
  ┌────────────────────┐
  │ ① OCI 보안 목록     │  ← 웹 콘솔에서 수동으로 열어야 함  (이 문서)
  │   (클라우드 방화벽)  │
  └────────┬───────────┘
           ▼
  ┌────────────────────┐
  │ ② 인스턴스 iptables │  ← 01-setup-vm.sh 가 자동으로 처리
  │   (우분투 내부 방화벽)│
  └────────┬───────────┘
           ▼
     마인크래프트 서버
```

②는 스크립트가 알아서 합니다. **①만 직접 해주시면 됩니다.**

---

## ① OCI 보안 목록에 인그레스 규칙 추가

1. OCI 콘솔 → **컴퓨트 → 인스턴스 → (내 인스턴스 클릭)**
2. 아래로 스크롤 → **기본 VNIC** 항목의 **서브넷** 링크 클릭
3. 서브넷 화면에서 **보안 목록(Security Lists)** → 목록에 있는 것 클릭
   (보통 `Default Security List for vcn-...`)
4. **인그레스 규칙 추가(Add Ingress Rules)** 클릭
5. 아래처럼 입력:

| 항목 | 값 |
|---|---|
| 무상태(Stateless) | **체크 안 함** |
| 소스 유형 | CIDR |
| 소스 CIDR | `0.0.0.0/0` |
| IP 프로토콜 | **TCP** |
| 소스 포트 범위 | (비워둠) |
| **대상 포트 범위** | **`25565`** |
| 설명 | `Minecraft` |

6. **인그레스 규칙 추가** 클릭

### UDP 규칙도 하나 더 (선택)

같은 방식으로 **IP 프로토콜만 UDP**, 대상 포트 `25565` 규칙을 하나 더 추가하면
좋습니다. 자바 에디션은 TCP만 쓰지만, 나중에 베드락 연동이나 음성 채팅 모드
(Simple Voice Chat 등)를 쓸 때 필요합니다.

> **소스 CIDR을 `0.0.0.0/0` 으로 여는 게 위험하지 않나요?**
> 마인크래프트 서버는 어차피 친구들이 각자 다른 IP에서 접속하므로 전체 개방이
> 일반적입니다. `online-mode=true`(정품 인증)와 화이트리스트로 보호하면 됩니다.
> SSH(22번)는 이미 열려 있는데, 이쪽은 다음 항목을 참고해 조여두는 걸 권합니다.

---

## SSH 포트 보안 조이기 (권장)

22번 포트는 전 세계에서 자동 스캔 공격이 끊임없이 들어옵니다.
SSH 키만 쓰면 뚫리진 않지만, 로그가 지저분해지고 자원이 낭비됩니다.

```bash
# fail2ban 설치 — 무차별 접속 시도 IP를 자동 차단
sudo apt update && sudo apt install -y fail2ban
sudo systemctl enable --now fail2ban

# 비밀번호 로그인 완전 차단 (SSH 키만 허용)
sudo sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart ssh
```

집 IP가 고정이라면, 보안 목록에서 22번 규칙의 소스 CIDR을 `내집IP/32` 로 바꾸면
가장 안전합니다. 단, IP가 바뀌면 본인도 못 들어가니 주의하세요.

---

## 열렸는지 확인하는 법

서버를 아직 안 켰으면 포트가 닫혀 있는 게 정상입니다.
**4단계까지 끝내고 서버를 켠 뒤** 아래로 확인하세요.

**서버 안에서 (LISTEN 상태 확인):**
```bash
sudo ss -tlnp | grep 25565
```
→ `LISTEN 0 ... *:25565` 이 나오면 서버는 정상 대기 중입니다.

**바깥에서 (실제 개방 확인):**
https://mcsrvstat.us 에 `공인IP:25565` 를 입력해보세요.
서버 정보가 뜨면 성공입니다.

셋 다 확인하는 순서:
1. `ss` 에 안 뜬다 → 마크 서버가 아직 안 켜졌거나 죽음 → `sudo mcctl log` 확인
2. `ss` 엔 뜨는데 밖에서 안 된다 → **보안 목록 규칙**을 다시 확인
3. 그래도 안 된다 → `sudo iptables -L INPUT -n --line-numbers` 로 25565 ACCEPT 규칙이
   REJECT 규칙보다 **위에** 있는지 확인

자세한 진단은 [문제 해결 문서](06-troubleshooting.md)에 있습니다.
